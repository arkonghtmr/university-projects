# HTML + CSS + JS версия

Это отдельная реализация лендинга PixelArt без React, Vite и npm-зависимостей.

## Запуск

Откройте `index.html` в браузере.

Файлы:

- `index.html` - структура страницы
- `styles.css` - все стили
- `script.js` - мобильное меню, аккордеоны, навигация и canvas-анимация
- `assets/` - PDF-файлы для iframe-фреймов и изображения для работ выпускников
