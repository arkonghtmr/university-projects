# Практическая работа 4

Wireframe главной страницы лендинга PixelArt.

## Что сделано

- Desktop-фрейм первого экрана с header, навигацией, кнопками и личным кабинетом.
- 12-колоночная сетка для контента шириной 1300 px.
- Серый wireframe без финальной графики, изображения заменены геометрическими фигурами.
- Отдельные макеты попапов: запись на курс и личный кабинет.

## Запуск

Откройте `index.html` в браузере.
