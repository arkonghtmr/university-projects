# Практическая работа 6

Wireframe адаптивной мобильной версии лендинга PixelArt.

## Что сделано

- Мобильный фрейм под iPhone 14 шириной 390 px.
- 8-колоночная сетка с margin 16 px и gutter 10 px.
- Контент desktop-версии сохранен и перестроен в одну колонку.
- Кнопки, меню и поля сделаны не меньше 44 px по высоте.
- Добавлены мобильные состояния попапов.

## Запуск

Откройте `index.html` в браузере.
