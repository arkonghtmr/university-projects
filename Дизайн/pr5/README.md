# Практическая работа 5

Wireframe остальных блоков лендинга PixelArt с учетом гештальт-принципов.

## Что сделано

- Полный desktop-макет: hero, аудитория, преимущества, программа, работы, тарифы, FAQ и footer.
- Сохранена 12-колоночная сетка и серая wireframe-палитра.
- В макете показаны принципы близости, общей области, схожести, продолжения, симметрии и замкнутости.
- Добавлены макеты попапов заявки и личного кабинета.

## Запуск

Откройте `index.html` в браузере.
